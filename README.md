# AIニュース

日付別の表紙一覧と、動く図入りのニュースを保存する静的サイトです。

公開URL：https://hn7000.github.io/ai-news/

- `index.html`：日付別の表紙一覧
- `issues/YYYY-MM-DD.html`：その日のニュース
- `運用ルール.md`：毎日の更新方針

初回号は2026年10月3日・4日のニュースを統合しています。

## 公開設定

GitHub Pagesは main ブランチの / (root) を公開元にしています。

## 定期更新

ChatGPTの定期タスク「AIニュース本棚の更新」を登録済みです。2026年10月5日から毎朝6時（日本時間）に、Google DriveのChatGPT・Grok収集分を統合してHTMLの作成・アップロードを開始します。サイトへの反映は生成とデプロイの完了後です。過去の日付のニュースは残します。

このリポジトリのファイル自体が定期処理を実行するわけではなく、ChatGPT側の定期タスクが更新します。
