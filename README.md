# ヒロのAIニュース

日付別の表紙一覧と、動く図入りのニュースを保存する静的サイトです。

- `index.html`：日付別の表紙一覧
- `issues/YYYY-MM-DD.html`：その日のニュース
- `運用ルール.md`：毎日の更新方針

初回号は2026年10月3日・4日のニュースを統合しています。

## GitHub Pagesの初期設定

リポジトリの Settings → Pages で、Source を Deploy from a branch、ブランチを main、フォルダを / (root) に指定して保存します。

自動更新タスクは、公開成功と接続権限の確認後に登録します。この一式を保存しただけでは定期実行は始まりません。
